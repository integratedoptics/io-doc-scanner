Standardise country, region and phone automatically

Country names are matched against your ERPNext territory list, region abbreviations such as CA are written out in full, and phone numbers get the international code of the card's country. A number with no country to go on is left exactly as printed and flagged.

ERPNext connection

Must exactly match an existing Supplier Type in ERPNext (Buying → Supplier Type) — required whenever a Supplier record is created from a card or a scanned document, otherwise ERPNext rejects it.

The photo is stored as a private attachment on the contact. If ERPNext does not yet know a salutation, gender or job title from a card, the app can add it to the matching list; countries, territories and departments are never invented and are reported instead.

Create the key and secret in ERPNext under User → API Access → Generate Keys. Credentials are kept only on this phone. Use an https address so nothing travels in the clear.

Document field extraction (Accounts Documents)

Used to read purchase invoices, customs declarations, CD invoices and shipping invoices you scan and pull out their fields (document number/date, supplier, PO reference, totals) with Claude Sonnet 5. On the Windows/macOS app, which has no on-device OCR, this same key is also used to read business-card photos directly — on Android/iOS, cards are still read on-device and this key isn’t used for them. Separate from the AI cleanup key below, which may be a different provider. Leave blank to enter fields by hand instead.

AI cleanup (optional)

Enabled
Also look for a LinkedIn profile

The key is stored only on this phone. When AI cleanup is on, the recognised text of a card is sent to the endpoint you configure so it can repair typical OCR mistakes (l/i, 0/O, missing dots in domains). Leave it off to stay completely offline.

The LinkedIn lookup asks the same model for the person's public profile URL. Models cannot browse LinkedIn, so a returned address is a suggestion: it is marked as unverified and you should tap it to check before exporting.

About

Card Scanner 1.2 — business card capture with ERPNext-ready Excel export and direct ERPNext synchronisation. On-device text recognition, standardised countries, regions and phone numbers. Styled to the Integrated Optics brandbook.

Scan a document

Invoices and customs papers in English, Lithuanian or German. A PDF's text is read on the device and filled in by a built-in reader straight away; with an Anthropic key set in Settings, Claude then reads it too (scans and photos are sent to Claude as a picture). Check every field before approving.
